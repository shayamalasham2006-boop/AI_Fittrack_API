# AI FitTrack – Phase-Wise Project

This project is organized into the same 8-phase structure used for the previous AI/ML/Gen-AI projects.

## Phases
1. Brainstorming & Ideation
2. Requirement Analysis
3. Project Design Phase
4. Project Planning Phase
5. Project Development Phase
6. Project Testing

## Actual Source Code
The original submitted FitTrack backend is preserved in `Project Source Code/`.

## Project
AI FitTrack is a RESTful fitness tracking backend built with Node.js, Express.js, MongoDB/Mongoose, JWT, bcryptjs and Google Gemini AI.
